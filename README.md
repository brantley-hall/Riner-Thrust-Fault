# Riner Thrust Fault Exploration

## 🏔️ Project Overview
Interactive geological investigation of the thrust fault running through property in Riner, Virginia.

## 📁 Project Structure
```
riner-thrust-fault/
├── index.html              # Main exploration page
├── assets/                 # Static assets
│   ├── images/            # Geological photos and maps
│   ├── css/               # Custom stylesheets
│   └── js/                # JavaScript files
├── data/                  # Geological data files
│   ├── coordinates.json   # GPS coordinates and mapping data
│   ├── samples.json       # Rock sample data
│   └── observations.json  # Field observations
├── docs/                  # Documentation
│   ├── methodology.md     # Research methods
│   ├── bibliography.md    # References and sources
│   └── field-notes.md     # Field observation notes
└── README.md              # This file
```

## 🎯 Features
- **Interactive Mapping**: Leaflet-based map showing fault location and observation points
- **Geological Timeline**: Visual history of the fault formation
- **Photo Gallery**: Field observations and rock samples
- **Data Visualization**: Geological data and measurements
- **Responsive Design**: Works on desktop and mobile devices

## 🔬 Geological Information
- **Fault Type**: Thrust fault
- **Location**: Riner, Virginia (Montgomery County)
- **Age**: Late Paleozoic (Appalachian orogeny)
- **Rock Types**: Metamorphic basement with sedimentary cover

## 📊 Data Collection
- GPS coordinates for fault trace
- Rock sample analysis
- Field observations
- Topographic mapping
- Photographic documentation

## 🚀 Getting Started
1. Clone this repository
2. Add your geological data to the `data/` folder
3. Add photos to `assets/images/`
4. Customize the map coordinates and fault line
5. Deploy to GitHub Pages or your preferred hosting
